# Instagram publishing subset

Curated API, not a full provider emulation. Acme is scenario configuration, not server behavior. Bearer authentication, create/read state, invalid inputs, account isolation, and unsupported routes are modeled. Provider rate limits, OAuth authorization, analytics, and remote media fetching are outside this subset.
