## Prerequisites

You need macOS or Linux on `amd64` or `arm64`, plus one of `curl` or `wget`.

## Install the CLI

The release workflow publishes `fab` binaries on every `v*` tag. The installer
downloads the right one for your machine:

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/install.sh | sh
```

It installs to `/usr/local/bin` when that directory is writable; otherwise it
uses `~/.local/bin`. If the installer prints a PATH hint, add it to your shell
profile and open a new shell.

```bash
fab --help
```

## Run an environment

Run a command with the built-in Acme Gmail environment available as local
environment variables:

```bash
fab run acme-gmail -- \
  sh -c 'curl -sS -H "Authorization: Bearer $FAB_SUPPORT_MAIL_TOKEN" \
  "$FAB_SUPPORT_MAIL_URL/gmail/v1/users/me/profile"'
```

You should get the Acme Gmail profile back. When the command exits, the
environment and its state are gone.

For a multi-service Acme world whose mail, chat, board, and CRM records share
the same people and incident IDs, see
[Acme Support Desk](/resources/environments/acme-support-desk).

## Connect your application

`fab run` starts the environment only for the command it wraps. Choose one of
two connection modes for that command.

### Direct base URL

Use this when your application can read its API base URL from configuration.
Fabricate injects a local service URL and token; point your Gmail client at
`$FAB_SUPPORT_MAIL_URL/gmail/v1` while it runs under `fab run`.

For a small FastAPI application using `httpx`, make the base URL configurable:

```python
import os

import httpx
from fastapi import FastAPI

app = FastAPI()
gmail_base_url = os.getenv("GMAIL_API_BASE_URL", "https://gmail.googleapis.com/gmail/v1")

@app.get("/profile")
def profile():
    response = httpx.get(
        f"{gmail_base_url}/users/me/profile",
        headers={"Authorization": f"Bearer {os.environ['FAB_SUPPORT_MAIL_TOKEN']}"},
    )
    response.raise_for_status()
    return response.json()
```

Run it with the local URL only for this process:

```bash
fab run acme-gmail -- \
  sh -c 'GMAIL_API_BASE_URL="$FAB_SUPPORT_MAIL_URL/gmail/v1" uvicorn main:app'
```

### Transparent proxy

Use `--proxy` when your application already calls normal provider hosts and
you do not want to add a Fabricate base-URL configuration. Fabricate injects a
process-scoped HTTPS proxy and CA trust settings, then routes supported Gmail
and Google OAuth traffic to the local environment. Other destinations pass
through unchanged unless the environment sets `proxy.unknown_hosts: reject`.
Do not send `$FAB_SUPPORT_MAIL_TOKEN` on these requests: the proxy replaces
`Authorization` on routed hosts.

For an existing FastAPI app that uses `httpx`'s default environment-aware
transport, keep the normal Gmail URL unchanged and omit the Fabricate token:

```python
@app.get("/profile")
def profile():
    response = httpx.get(
        "https://gmail.googleapis.com/gmail/v1/users/me/profile",
    )
    response.raise_for_status()
    return response.json()
```

```bash
fab run acme-gmail --proxy -- \
  uvicorn main:app
```

The same applies to an existing JavaScript application using Google's official
client: retain its normal Gmail construction and run it under the proxy. The
client may keep a refresh-token grant against `oauth2.googleapis.com/token`.
Fabricate answers that route with the synthetic access token; it does not
complete a real Google login or store customer credentials.

```js
import {google} from "googleapis";

const gmail = google.gmail({version: "v1", auth});
const profile = await gmail.users.getProfile({userId: "me"});
console.log(profile.data);
```

```bash
fab run acme-gmail --proxy -- \
  node app.mjs
```

Your client must respect standard proxy and CA environment variables. Use the
direct base URL when it pins certificates or bypasses proxy settings.

For a worker managed by an agent platform or a separate process supervisor,
continue with [Agent and workflow QA](/guides/agent-workflows).
