Acme Goods Shop is a ready-to-run environment for testing software that takes
an order from the storefront through payment, fulfillment, accounting, and
the warehouse. Every run starts from the same Bengaluru D2C shop and is
removed when the wrapped command exits.

Its manifest identifier is `acme-goods-shop`.

## Scenario data

Order `10482` is the join key. Priya Nair bought one `AG-TEE-02` and two
`AG-MUG-01` for ₹3097. The same number is the Shopify order, the Razorpay
payment, the Shiprocket airway bill, the Zoho sales order and invoice, the
WhatsApp message, the GA4 transaction, and a Redshift row.

| Join key | Where it appears |
| --- | --- |
| `10482` | Shopify order, Shiprocket `SR10482AWB`, Inventory `SO-10482`, Books `INV-10482`, Gupshup `msg_10482`, GA4 transaction, Redshift order |
| `pay_Acme10482` | Razorpay captured UPI payment and the August settlement CSV in Drive |
| `10483` | NDR on `SR10483AWB` ("Customer not available"), Inventory `SO-10483`, Airbyte `job_fail_ndr` |
| `10484` | Refunded tee, Razorpay `rfnd_Acme10484`, Shiprocket `RET-10484`, Books credit note `CN-10484` |

`INV-4812` is also in Zoho Books, Slack, and Redshift. That is the Northwind
SaaS duplicate charge, not a shop order. Refunding `10484` does not close it.

Zoho Inventory is mounted at `/inventory/` and Zoho Books at `/books/` on
`www.zohoapis.com`, so both ledgers run in this environment. Shopify here is
only Acme Goods. The four-shop view is
[Acme Commerce Agency](/resources/environments/acme-commerce-agency).

## Get started

Paste this command to download the manifest and read order `10482` from the
shop, the payment, the courier, inventory, and books. You do not need to clone
Fabricate.

<CommandOutput id="acme-goods-shop-10482" />

`--proxy` keeps each provider’s normal hostname. Direct URLs and the rest of
each API are on the integration pages linked above.
