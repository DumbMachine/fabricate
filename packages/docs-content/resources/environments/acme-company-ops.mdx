Acme Company Ops is a ready-to-run environment for testing software that works
across Acme's people and the SaaS side of the business. Every run starts from
the same company and is removed when the wrapped command exits.

Its manifest identifier is `acme-company-ops`.

## Scenario data

Invoice `INV-4812` is the join key. Northwind Traders was billed 1240 USD
twice. Zoho Books still shows the invoice as sent. Chargebee shows both
payments. Gainsight and the service desk call it out. Mail, chat, the board,
and CRM already carry the same dispute.

| Join key | Where it appears |
| --- | --- |
| `INV-4812` | Gmail thread, Intercom 101, Asana `task-double-charge`, HubSpot deal 301, Chargebee `sub_northwind_checkout`, Zoho Books, Gainsight, Jira `ITSM-4812`, Drive `INV-4812-northwind.pdf` |
| `pay_saas_4812` and `pay_saas_4812b` | The duplicate pair. Books stores them unapplied. Chargebee counts both. |
| `val@acme.example` | Okta `00u-val` and BambooHR employee 101 |
| `contoso-eu` | Intercom 102, Asana `task-sso`, Gainsight, Jira `ITSM-SSO` |

This invoice is not shop order `10484`. The shop refund lives in
[Acme Goods Shop](/resources/environments/acme-goods-shop). Gmail is mounted at
`/gmail/` and Drive at `/drive/` on `www.googleapis.com`, so the inbox and the
file cabinet both run here.

## Get started

Paste this command to download the manifest and read `INV-4812` from mail,
Chargebee, Zoho Books, and the service desk, then read Val from Okta. You do
not need to clone Fabricate.

<CommandOutput id="acme-company-ops-inv-4812" />

`--proxy` keeps each provider’s normal hostname.
[Acme Billing Ops](/resources/environments/acme-billing-ops) is the smaller
mail, chat, and CRM slice of the same invoice.
