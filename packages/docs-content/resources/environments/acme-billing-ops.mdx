Acme Billing Ops is a ready-to-run environment for testing software that
reconciles customer billing mail with chat and CRM. Every run starts from the
same Northwind invoice dispute and is removed when the wrapped command exits.

Its manifest identifier is `acme-billing-ops`.

## Scenario data

This environment is a billing slice of the same Acme world as
[Acme Support Desk](/resources/environments/acme-support-desk). The join key is
invoice `INV-4812`: Dana Whitfield at Northwind was charged twice for $1,240.

| Join key | Gmail | Intercom | HubSpot |
| --- | --- | --- | --- |
| `INV-4812` | thread `thr-double-charge` | open conversation `101` | deal `301` (`invoice`: `INV-4812`, amount `12400`) |
| `dana@northwind.example` | From on both billing messages | contact `contact-dana` | contact `101`, company Northwind Traders |

The inbox still contains the rest of Acme's support mail, and CRM still has the
Contoso SSO ticket. Those records are context, not the billing job. Closing the
Northwind deal or refunding Dana without reading both the mail thread and the
open Intercom conversation is the kind of incomplete write this fixture is meant
to catch.

For the engineering board that tracks the same invoice, use
[Acme Support Desk](/resources/environments/acme-support-desk).

## Get started

Paste this command to download the environment manifest, start the three
services, and read `INV-4812` from mail, chat, and CRM. You do not need to clone
Fabricate.

for API coverage, response examples, and the direct-URL option.
