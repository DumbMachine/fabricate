Acme Commerce Agency is a ready-to-run environment for testing software that
operates more than one Shopify shop. Every run starts from the same four
storefronts and is removed when the wrapped command exits.

Its manifest identifier is `acme-commerce-agency`.

## Scenario data

One Shopify service owns all four domains. A request to
`acme-goods.myshopify.com` sees Priya's order `10482`. A request to
`northwind-market.myshopify.com` sees Jules Okonkwo's kettle order `10490`.
A request to `tinyshop.myshopify.com` sees Anita Desai's candle order `10491`.
Fernworks Studio is the fourth shop and has no order in this seed.

| Shop | Order | Payment | Shipment |
| --- | --- | --- | --- |
| Acme Goods | `10482` | `pay_Acme10482` | `SR10482AWB` in transit |
| Northwind Market | `10490` | `pay_NW10490` | `SR10490AWB` delivered |
| TinyShop | `10491` | `pay_TS10491` | no Shiprocket row |

impact.com action `act_10482` pays partner `partner_northwind` ₹150 on the
Acme Goods order, and that payout is still pending. The in-house warehouse
view, with Zoho Inventory and the Redshift copy, is
[Acme Goods Shop](/resources/environments/acme-goods-shop).

## Get started

Paste this command to download the manifest and read the three shop orders
from their own hostnames, plus the Northwind payment and the affiliate action.
You do not need to clone Fabricate.

<CommandOutput id="acme-commerce-agency-shops" />

`--proxy` keeps each shop hostname. The same Shopify token is injected for
every domain.
