Acme's Gmail is a ready-to-run environment for testing software that reads,
organizes, or sends support mail. Every run starts with the same Acme Corp
support inbox and is removed when the wrapped command exits.

Its manifest identifier is `acme-gmail`.

## Scenario data

`gmail.acme-corp.v1` seeds 12 handcrafted messages across support threads,
including double charges, SSO outages, refunds, CSV exports, webhooks, and API
key rotation. It gives an inbox workflow realistic threads and labels to search
and change instead of an empty mailbox.

The scenario is the initial state. Your application can change messages,
threads, and labels during its run; the next run begins from the original Acme
Corp data again.

For the same inbox composed with Intercom, Asana, and HubSpot so those records
join across services, see [Acme Support Desk](/resources/environments/acme-support-desk).
