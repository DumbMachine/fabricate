Acme's Gmail is a ready-to-run environment for testing software that reads,
organizes, or sends support mail. Every run starts with the same Acme Corp
support inbox and is removed when the wrapped command exits.

Its manifest identifier is `acme-gmail`.

## Included integrations

- <img src="https://logos.composio.dev/api/gmail" alt="" width="20" height="20" /> **[Gmail](/resources/integrations/gmail)** — service name: `support-mail`; scenario: `gmail.acme-corp.v1`.

## Scenario data

`gmail.acme-corp.v1` seeds 12 handcrafted messages across support threads,
including double charges, SSO outages, refunds, CSV exports, webhooks, and API
key rotation. It gives an inbox workflow realistic threads and labels to search
and change instead of an empty mailbox.

The scenario is the initial state. Your application can change messages,
threads, and labels during its run; the next run begins from the original Acme
Corp data again.

## Get started

Paste this command to download the environment manifest, start the Gmail
service, and list the seeded messages. You do not need to clone Fabricate.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-gmail.yaml | \
  fab run --environment /dev/stdin -- \
    sh -c 'curl -sS -H "Authorization: Bearer $FAB_SUPPORT_MAIL_TOKEN" \
      "$FAB_SUPPORT_MAIL_URL/gmail/v1/users/me/messages"'
```

Fabricate injects `FAB_SUPPORT_MAIL_URL` and `FAB_SUPPORT_MAIL_TOKEN` into the
wrapped process. See [Gmail](/resources/integrations/gmail) for the response,
direct-URL integration, and transparent-proxy setup.
