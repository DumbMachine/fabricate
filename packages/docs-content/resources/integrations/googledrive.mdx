## Integration

| | Details |
| --- | --- |
| API | Google Drive v3 |
| Auth | Synthetic bearer token. Direct mode requires it; proxy mode injects it. |
| Hosts | `www.googleapis.com` (`/drive/`) |
| Direct URL | Yes |
| Transparent proxy | Yes |

### Start it with a direct URL

Use `fab run` without `--proxy`. The command below downloads Fabricate's
example manifest directly, so you do not need to clone this repository.
Fabricate injects a URL and a short-lived token for the service name in that
manifest. Direct calls must send that token.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-googledrive.yaml | \
  fab run /dev/stdin -- \
    sh -c 'curl -sS -H "Authorization: Bearer $FAB_GOOGLEDRIVE_TOKEN" \
      "$FAB_GOOGLEDRIVE_URL/drive/v3/files/file-razorpay-settlement-2026-08-25"'
```

The service is named `googledrive` in the example manifest, so the variables are
`FAB_GOOGLEDRIVE_URL` and `FAB_GOOGLEDRIVE_TOKEN`.

### Start it through the proxy

Use this when your app uses the normal Google Drive URLs and follows standard
proxy and CA environment variables. This one-paste check calls Drive's normal
production hostname; replace the final `curl` with your app. Omit
`$FAB_GOOGLEDRIVE_TOKEN` here: the proxy replaces `Authorization` on routed
hosts with the environment's ephemeral token.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-googledrive.yaml | \
  fab run /dev/stdin --proxy -- \
    curl -sS https://www.googleapis.com/drive/v3/files/file-razorpay-settlement-2026-08-25
```

Fabricate handles Drive paths on `www.googleapis.com`. Gmail keeps `/gmail/`
on that same host. Other hosts are forwarded unchanged; set
`proxy.unknown_hosts: reject` for an isolated, fail-closed conformance test.

The proxy will not help an application that pins certificates or ignores proxy
settings. In that case, use the direct URL.
