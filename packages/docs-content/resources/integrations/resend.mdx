Emails and domains. Local Resend v1 that keeps outbox state across
requests.

## Integration

| | Details |
| --- | --- |
| API | Resend v1 |
| Auth | Synthetic bearer token |
| Hosts | `api.resend.com` |
| Direct URL | Yes |
| Transparent proxy | Yes |

### Start it with a direct URL

Use `fab run` without `--proxy`. The command below downloads Fabricate's
example manifest directly, so you do not need to clone this repository.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-resend.yaml | \
  fab run /dev/stdin -- \
    sh -c 'curl -sS -H "Authorization: Bearer $FAB_RESEND_TOKEN" "$FAB_RESEND_URL/emails"'
```

The service is named `resend` in the example manifest, so the variables are
`FAB_RESEND_URL` and `FAB_RESEND_TOKEN`.

### Start it through the proxy

Use this when your app uses the normal Resend URLs. This one-paste check
calls Resend's production hostname. Omit `$FAB_RESEND_TOKEN`; the proxy replaces `Authorization` on that host with the environment's ephemeral token.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-resend.yaml | \
  fab run /dev/stdin --proxy -- \
    curl -sS https://api.resend.com/emails
```

Fabricate handles `api.resend.com` locally. Other hosts are forwarded unchanged.
