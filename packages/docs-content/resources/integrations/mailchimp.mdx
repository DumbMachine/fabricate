Fabricate ships a Mailchimp 3.0 resource with a strict local API and a
synthetic bearer token. It covers lists, members, and campaigns in the included Acme Mailchimp
environment.

## Scenarios

| Scenario | What it gives you |
| --- | --- |
| `mailchimp.minimal.v1` | Empty Mailchimp state for a clean test. |
| `mailchimp.acme-audience.v1` | Dana at Northwind, INV-4812, Contoso SSO, and Fernworks. |

## Integration options

| Option | Supported | Use it when |
| --- | --- | --- |
| Direct base URL | Yes | Your client can use a local URL or root URL. |
| Transparent proxy | Yes | Your client must keep Mailchimp’s normal hostnames. |

### Start it with a direct URL

Use `fab run` without `--proxy`. The command below downloads Fabricate's
example manifest directly, so you do not need to clone this repository.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-mailchimp.yaml | \
  fab run --environment /dev/stdin -- \
    sh -c 'curl -sS -H "Authorization: Bearer $FAB_MAILCHIMP_TOKEN" "$FAB_MAILCHIMP_URL/3.0/lists/acme-customers/members"'
```

The service is named `mailchimp` in the example manifest, so the variables are
`FAB_MAILCHIMP_URL` and `FAB_MAILCHIMP_TOKEN`.

### Start it through the proxy

Use this when your app uses the normal Mailchimp URLs. This one-paste check
calls Mailchimp's production hostname; the proxy supplies the local token.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-mailchimp.yaml | \
  fab run --environment /dev/stdin --proxy -- \
    curl -sS https://us1.api.mailchimp.com/3.0/lists/acme-customers/members
```

Fabricate handles `us1.api.mailchimp.com` locally. Other hosts are forwarded unchanged.
