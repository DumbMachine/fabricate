WhatsApp app, templates, messages, and delivery status. Local Gupshup
WhatsApp v1 that keeps message state across requests.

## Integration

| | Details |
| --- | --- |
| API | Gupshup WhatsApp v1 |
| Auth | Synthetic bearer token, or an `apikey` header with the same token |
| Hosts | `api.gupshup.io` |
| Direct URL | Yes |
| Transparent proxy | Yes |

Gupshup clients usually send `apikey`. Fabricate also accepts
`Authorization: Bearer`, which is what the proxy writes. Both values are the
same synthetic token.

### Start it with a direct URL

Use `fab run` without `--proxy`. The command below downloads Fabricate's
example manifest directly, so you do not need to clone this repository.
Fabricate injects a URL and a short-lived token for the service name in that
manifest.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-gupshup.yaml | \
  fab run /dev/stdin -- \
    sh -c 'curl -sS -H "Authorization: Bearer $FAB_GUPSHUP_TOKEN" \
      "$FAB_GUPSHUP_URL/wa/api/v1/msg"'
```

The service is named `gupshup` in the example manifest, so the variables are
`FAB_GUPSHUP_URL` and `FAB_GUPSHUP_TOKEN`. The same call with the Gupshup
header is:

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-gupshup.yaml | \
  fab run /dev/stdin -- \
    sh -c 'curl -sS -H "apikey: $FAB_GUPSHUP_TOKEN" \
      "$FAB_GUPSHUP_URL/wa/api/v1/msg/msg_10482"'
```

### Start it through the proxy

Use this when your app uses the normal Gupshup URLs and follows standard proxy
and CA environment variables. This one-paste check calls Gupshup's normal
production hostname; replace the final `curl` with your app. Omit
`$FAB_GUPSHUP_TOKEN` here: the proxy replaces `Authorization` on routed hosts
with the environment's ephemeral token.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-gupshup.yaml | \
  fab run /dev/stdin --proxy -- \
    curl -sS https://api.gupshup.io/wa/api/v1/msg
```

Fabricate handles `api.gupshup.io` locally. Other hosts are forwarded unchanged;
set `proxy.unknown_hosts: reject` for an isolated, fail-closed conformance test.

The proxy will not help an application that pins certificates or ignores proxy
settings. In that case, use the direct URL.
