Fabricate ships a Val Town v1 resource with a strict local API and a
synthetic bearer token. It covers val list, get, and create in the included
Acme Val Town environment.

## Scenarios

| Scenario | What it gives you |
| --- | --- |
| `valtown.minimal.v1` | Empty Val Town state for a clean test. |
| `valtown.acme-vals.v1` | Acme webhook, billing, and docs vals. |

## Integration options

| Option | Supported | Use it when |
| --- | --- | --- |
| Direct base URL | Yes | Your client can use a local URL or root URL. |
| Transparent proxy | Yes | Your client must keep Val Town’s normal hostnames. |

### Start it with a direct URL

Use `fab run` without `--proxy`. The command below downloads Fabricate's
example manifest directly, so you do not need to clone this repository.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-valtown.yaml | \
  fab run --environment /dev/stdin -- \
    sh -c 'curl -sS -H "Authorization: Bearer $FAB_VALTOWN_TOKEN" "$FAB_VALTOWN_URL/v2/vals"'
```

The service is named `valtown` in the example manifest, so the variables are
`FAB_VALTOWN_URL` and `FAB_VALTOWN_TOKEN`.

### Start it through the proxy

Use this when your app uses the normal Val Town URLs. This one-paste check
calls Val Town's production hostname; the proxy supplies the local token.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-valtown.yaml | \
  fab run --environment /dev/stdin --proxy -- \
    curl -sS https://api.val.town/v2/vals
```

Fabricate handles `api.val.town` locally. Other hosts are forwarded unchanged.
