Fabricate ships a Close v1 resource with a strict local API and a
synthetic bearer token. It covers leads, contacts, and opportunities in the included Acme Close
environment.

## Scenarios

| Scenario | What it gives you |
| --- | --- |
| `close.minimal.v1` | Empty Close state for a clean test. |
| `close.acme-pipeline.v1` | Dana at Northwind, INV-4812, Contoso SSO, and Fernworks. |

## Integration options

| Option | Supported | Use it when |
| --- | --- | --- |
| Direct base URL | Yes | Your client can use a local URL or root URL. |
| Transparent proxy | Yes | Your client must keep Close’s normal hostnames. |

### Start it with a direct URL

Use `fab run` without `--proxy`. The command below downloads Fabricate's
example manifest directly, so you do not need to clone this repository.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-close.yaml | \
  fab run --environment /dev/stdin -- \
    sh -c 'curl -sS -H "Authorization: Bearer $FAB_CLOSE_TOKEN" "$FAB_CLOSE_URL/api/v1/lead/"'
```

The service is named `close` in the example manifest, so the variables are
`FAB_CLOSE_URL` and `FAB_CLOSE_TOKEN`.

### Start it through the proxy

Use this when your app uses the normal Close URLs. This one-paste check
calls Close's production hostname; the proxy supplies the local token.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-close.yaml | \
  fab run --environment /dev/stdin --proxy -- \
    curl -sS https://api.close.com/api/v1/lead/
```

Fabricate handles `api.close.com` locally. Other hosts are forwarded unchanged.
