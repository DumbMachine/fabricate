Fabricate ships a GitHub v1 resource with a local API driven by the official GitHub OpenAPI document and a synthetic bearer token. Every operation in that document is implemented. The included Acme GitHub environment seeds the walkthrough scenario.

## Scenarios

| Scenario | What it gives you |
| --- | --- |
| `github.minimal.v1` | Empty GitHub state for a clean test. |
| `github.acme-issues.v1` | Checkout reliability, Contoso SSO, and INV-4812 issues on acme/web. |

## Integration options

| Option | Supported | Use it when |
| --- | --- | --- |
| Direct base URL | Yes | Your client can use a local URL or root URL. |
| Transparent proxy | Yes | Your client must keep GitHub’s normal hostnames. |

### Start it with a direct URL

Use `fab run` without `--proxy`. The command below downloads Fabricate's
example manifest directly, so you do not need to clone this repository.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-github.yaml | \
  fab run --environment /dev/stdin -- \
    sh -c 'curl -sS -H "Authorization: Bearer $FAB_GITHUB_TOKEN" "$FAB_GITHUB_URL/repos/acme/web/issues"'
```

The service is named `github` in the example manifest, so the variables are
`FAB_GITHUB_URL` and `FAB_GITHUB_TOKEN`.

### Start it through the proxy

Use this when your app uses the normal GitHub URLs. This one-paste check
calls GitHub's production hostname; the proxy supplies the local token.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-github.yaml | \
  fab run --environment /dev/stdin --proxy -- \
    curl -sS https://api.github.com/repos/acme/web/issues
```

Fabricate handles `api.github.com` locally. Other hosts are forwarded unchanged.

The first surface is repository issues only. It does not emulate Git smart HTTP,
clone, fetch, push, pull-request merges, Actions, or file mutation.
