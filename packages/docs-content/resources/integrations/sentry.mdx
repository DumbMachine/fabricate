Fabricate ships a Sentry v1 resource with a strict local API and a
synthetic bearer token. It covers organization project list, get, and create in the included
Acme Sentry environment.

## Scenarios

| Scenario | What it gives you |
| --- | --- |
| `sentry.minimal.v1` | Empty Sentry state for a clean test. |
| `sentry.acme-projects.v1` | Acme web, API, and docs Sentry projects. |

## Integration options

| Option | Supported | Use it when |
| --- | --- | --- |
| Direct base URL | Yes | Your client can use a local URL or root URL. |
| Transparent proxy | Yes | Your client must keep Sentry’s normal hostnames. |

### Start it with a direct URL

Use `fab run` without `--proxy`. The command below downloads Fabricate's
example manifest directly, so you do not need to clone this repository.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-sentry.yaml | \
  fab run --environment /dev/stdin -- \
    sh -c 'curl -sS -H "Authorization: Bearer $FAB_SENTRY_TOKEN" "$FAB_SENTRY_URL/api/0/organizations/acme/projects/"'
```

The service is named `sentry` in the example manifest, so the variables are
`FAB_SENTRY_URL` and `FAB_SENTRY_TOKEN`.

### Start it through the proxy

Use this when your app uses the normal Sentry URLs. This one-paste check
calls Sentry's production hostname; the proxy supplies the local token.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-sentry.yaml | \
  fab run --environment /dev/stdin --proxy -- \
    curl -sS https://us.sentry.io/api/0/organizations/acme/projects/
```

Fabricate handles `us.sentry.io` locally. Other hosts are forwarded unchanged.
