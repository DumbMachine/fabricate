Service desks, request types, customer requests, and comments. Local Jira
Service Management REST API 3 that keeps desk state across requests.

## Integration

| | Details |
| --- | --- |
| API | Jira Service Management REST API 3 |
| Auth | Synthetic bearer token |
| Hosts | `acme.atlassian.net` |
| Direct URL | Yes |
| Transparent proxy | Yes |

Jira Cloud ad-hoc clients send HTTP Basic (the account email and an API
token). OAuth 2.0 clients send `Authorization: Bearer`. Fabricate's proxy
writes that bearer header, and this resource accepts it.

### Start it with a direct URL

Use `fab run` without `--proxy`. The command below downloads Fabricate's
example manifest directly, so you do not need to clone this repository.
Fabricate injects a URL and a short-lived token for the service name in that
manifest.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-jsm.yaml | \
  fab run /dev/stdin -- \
    sh -c 'curl -sS -H "Authorization: Bearer $FAB_JSM_TOKEN" \
      "$FAB_JSM_URL/rest/servicedeskapi/request"'
```

The service is named `jsm` in the example manifest, so the variables are
`FAB_JSM_URL` and `FAB_JSM_TOKEN`.

### Start it through the proxy

Use this when your app uses the normal Jira Service Management URLs and
follows standard proxy and CA environment variables. This one-paste check
calls the service desk hostname; replace the final `curl` with your app. Omit
`$FAB_JSM_TOKEN` here: the proxy replaces `Authorization` on routed hosts
with the environment's ephemeral token.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-jsm.yaml | \
  fab run /dev/stdin --proxy -- \
    curl -sS https://acme.atlassian.net/rest/servicedeskapi/request
```

Fabricate handles `acme.atlassian.net` requests whose path starts with
`/rest/servicedeskapi/`. Other hosts are forwarded unchanged; set
`proxy.unknown_hosts: reject` for an isolated, fail-closed conformance test.

The proxy will not help an application that pins certificates or ignores proxy
settings. In that case, use the direct URL.
