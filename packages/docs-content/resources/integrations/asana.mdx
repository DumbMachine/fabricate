Fabricate ships an Asana REST API 1.0 resource with a strict local API and a
synthetic bearer token. It covers users, workspaces, projects, tasks, sections,
and stories in the included Acme Asana environment.

## Scenarios

| Scenario | What it gives you |
| --- | --- |
| `asana.minimal.v1` | An empty Acme workspace for a clean test. |
| `asana.acme-sprint.v1` | A Checkout reliability project with five tasks, sections, and comments. |

## Integration options

| Option | Supported | Use it when |
| --- | --- | --- |
| Direct base URL | Yes | Your client can use a local URL or root URL. |
| Transparent proxy | Yes | Your client must keep Asana’s normal hostnames. |

### Start it with a direct URL

Use `fab run` without `--proxy`. The command below downloads Fabricate's
example manifest directly, so you do not need to clone this repository.
Fabricate injects a URL and a short-lived token for the service name in that
manifest.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-asana.yaml | \
  fab run --environment /dev/stdin -- \
    sh -c 'curl -sS -H "Authorization: Bearer $FAB_ASANA_TOKEN" \
      "$FAB_ASANA_URL/projects/proj-checkout/tasks"'
```

The service is named `asana` in the example manifest, so the variables are
`FAB_ASANA_URL` and `FAB_ASANA_TOKEN`.

### Start it through the proxy

Use this when your app uses the normal Asana URLs and follows standard proxy
and CA environment variables. This one-paste check calls Asana's normal
production hostname; replace the final `sh -c ...` command with your app.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-asana.yaml | \
  fab run --environment /dev/stdin --proxy -- \
    sh -c 'curl -sS -H "Authorization: Bearer $FAB_ASANA_TOKEN" \
      "https://app.asana.com/api/1.0/projects/proj-checkout/tasks"'
```

Fabricate handles `app.asana.com` locally. Other hosts are forwarded unchanged;
set `proxy.unknown_hosts: reject` for an isolated, fail-closed conformance test.

The proxy will not help an application that pins certificates or ignores proxy
settings. In that case, use the direct URL.
