Programs, partners, actions, and notes. Local impact.com Brand API that keeps
affiliate state across requests.

## Integration

| | Details |
| --- | --- |
| API | impact.com Brand API v14 |
| Auth | Synthetic bearer token. impact.com uses HTTP Basic (Account SID and Auth Token). |
| Hosts | `api.impact.com` |
| Direct URL | Yes |
| Transparent proxy | Yes |

Account `acct-acme`. Program `1001` is Acme Goods affiliates. The seeded action
for order `10482` pays Northwind Creators ₹150 (15000 paise) and is `PENDING`.
`Payout` is in rupees. Live impact.com returns XML unless the client sends
`Accept: application/json`; this resource always returns JSON.

### Start it with a direct URL

Use `fab run` without `--proxy`. The command below downloads Fabricate's
example manifest directly, so you do not need to clone this repository.
Fabricate injects a URL and a short-lived token for the service name in that
manifest.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-impact.yaml | \
  fab run /dev/stdin -- \
    sh -c 'curl -sS -H "Authorization: Bearer $FAB_IMPACT_TOKEN" -H "Accept: application/json" \
      "$FAB_IMPACT_URL/Advertisers/acct-acme/Actions?CampaignId=1001&Oid=10482"'
```

The service is named `impact` in the example manifest, so the variables are
`FAB_IMPACT_URL` and `FAB_IMPACT_TOKEN`.

The response is the pending Acme Goods action for order 10482. `Payout` is rupees, so ₹150 is `150`. The same action is also `GET /Advertisers/acct-acme/Actions/10482`.

### Start it through the proxy

Use this when your app uses the normal impact.com URLs and follows standard
proxy and CA environment variables. This one-paste check calls impact.com's
normal production hostname; replace the final `curl` with your app. Omit
`$FAB_IMPACT_TOKEN` here: the proxy replaces `Authorization` on routed hosts
with the environment's ephemeral token.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-impact.yaml | \
  fab run /dev/stdin --proxy -- \
    curl -sS -H "Accept: application/json" \
      "https://api.impact.com/Advertisers/acct-acme/Actions?CampaignId=1001&Oid=10482"
```

Fabricate handles `api.impact.com` locally. Other hosts are forwarded unchanged;
set `proxy.unknown_hosts: reject` for an isolated, fail-closed conformance test.

The proxy will not help an application that pins certificates or ignores proxy
settings. In that case, use the direct URL.
