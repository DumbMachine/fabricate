Fabricate ships a Cloudflare v1 resource with a local API driven by the official Cloudflare OpenAPI document and a synthetic bearer token. Every operation in that document is implemented. The included Acme Cloudflare environment seeds the walkthrough scenario.

## Scenarios

| Scenario | What it gives you |
| --- | --- |
| `cloudflare.minimal.v1` | Empty Cloudflare state for a clean test. |
| `cloudflare.acme-zones.v1` | Acme DNS zones for acme.example, docs, and web. |

## Integration options

| Option | Supported | Use it when |
| --- | --- | --- |
| Direct base URL | Yes | Your client can use a local URL or root URL. |
| Transparent proxy | Yes | Your client must keep Cloudflare’s normal hostnames. |

### Start it with a direct URL

Use `fab run` without `--proxy`. The command below downloads Fabricate's
example manifest directly, so you do not need to clone this repository.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-cloudflare.yaml | \
  fab run --environment /dev/stdin -- \
    sh -c 'curl -sS -H "Authorization: Bearer $FAB_CLOUDFLARE_TOKEN" "$FAB_CLOUDFLARE_URL/client/v4/zones"'
```

The service is named `cloudflare` in the example manifest, so the variables are
`FAB_CLOUDFLARE_URL` and `FAB_CLOUDFLARE_TOKEN`.

### Start it through the proxy

Use this when your app uses the normal Cloudflare URLs. This one-paste check
calls Cloudflare's production hostname; the proxy supplies the local token.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-cloudflare.yaml | \
  fab run --environment /dev/stdin --proxy -- \
    curl -sS https://api.cloudflare.com/client/v4/zones
```

Fabricate handles `api.cloudflare.com` locally. Other hosts are forwarded unchanged.
