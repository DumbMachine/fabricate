Vendors, security reviews, tests, documents, and uploads. Local Vanta v1 that
keeps compliance state across requests.

## Integration

| | Details |
| --- | --- |
| API | Vanta v1 |
| Auth | Synthetic bearer token. Vanta's Manage API uses an OAuth access token as a bearer. |
| Hosts | `api.vanta.com` |
| Direct URL | Yes |
| Transparent proxy | Yes |

### Start it with a direct URL

Use `fab run` without `--proxy`. The command below downloads Fabricate's
example manifest directly, so you do not need to clone this repository.
Fabricate injects a URL and a short-lived token for the service name in that
manifest.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-vanta.yaml | \
  fab run /dev/stdin -- \
    sh -c 'curl -sS -H "Authorization: Bearer $FAB_VANTA_TOKEN" \
      "$FAB_VANTA_URL/v1/tests"'
```

The service is named `vanta` in the example manifest, so the variables are
`FAB_VANTA_URL` and `FAB_VANTA_TOKEN`.

attention and cites the deprovisioned contractor and Drive file

### Start it through the proxy

Use this when your app uses the normal Vanta URLs and follows standard proxy
and CA environment variables. This one-paste check calls Vanta's normal
production hostname; replace the final `curl` with your app. Omit
`$FAB_VANTA_TOKEN` here: the proxy replaces `Authorization` on routed hosts
with the environment's ephemeral token.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-vanta.yaml | \
  fab run /dev/stdin --proxy -- \
    curl -sS https://api.vanta.com/v1/tests
```

Fabricate handles `api.vanta.com` locally. Other hosts are forwarded unchanged;
set `proxy.unknown_hosts: reject` for an isolated, fail-closed conformance test.

The proxy will not help an application that pins certificates or ignores proxy
settings. In that case, use the direct URL.
