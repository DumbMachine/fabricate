## Integration

| | Details |
| --- | --- |

| Direct URL | Yes |
| Transparent proxy | Yes |

### Start it with a direct URL

Use `fab run` without `--proxy`. The command below downloads Fabricate's
example manifest directly, so you do not need to clone this repository.
Fabricate injects a URL and a short-lived token for the service name in that
manifest.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-ga4.yaml | \
  fab run /dev/stdin -- \
    sh -c 'curl -sS -H "Authorization: Bearer $FAB_GA4_TOKEN" -H "Content-Type: application/json" \
      -d "{\"dateRanges\":[{\"startDate\":\"2026-08-01\",\"endDate\":\"2026-08-26\"}],\"dimensions\":[{\"name\":\"transactionId\"},{\"name\":\"sessionSource\"},{\"name\":\"sessionMedium\"},{\"name\":\"sessionCampaignName\"},{\"name\":\"eventName\"}],\"metrics\":[{\"name\":\"eventCount\"}]}" \
      "$FAB_GA4_URL/v1beta/properties/309712345:runReport"'
```

The service is named `ga4` in the example manifest, so the variables are
`FAB_GA4_URL` and `FAB_GA4_TOKEN`.

The response is the Acme Goods purchase and refund report. `10482` is the
WhatsApp campaign, `10483` is Google ads, and `10484` is the refund event:

### Start it through the proxy

Use this when your app uses the normal Analytics Data API URLs and follows
standard proxy and CA environment variables. This one-paste check calls the
production hostname; replace the final `curl` with your app. Omit
`$FAB_GA4_TOKEN` here: the proxy replaces `Authorization` on routed hosts
with the environment's ephemeral token.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-ga4.yaml | \
  fab run /dev/stdin --proxy -- \
    curl -sS -H 'Content-Type: application/json' \
      -d '{"dateRanges":[{"startDate":"2026-08-01","endDate":"2026-08-26"}],"dimensions":[{"name":"transactionId"},{"name":"sessionSource"},{"name":"sessionMedium"},{"name":"sessionCampaignName"},{"name":"eventName"}],"metrics":[{"name":"eventCount"}]}' \
      https://analyticsdata.googleapis.com/v1beta/properties/309712345:runReport
```

Fabricate handles `analyticsdata.googleapis.com` locally. Other hosts are
forwarded unchanged; set `proxy.unknown_hosts: reject` for an isolated,
fail-closed conformance test.

The proxy will not help an application that pins certificates or ignores proxy
settings. In that case, use the direct URL.
