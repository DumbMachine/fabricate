Domains, events, and send. Local Mailgun v3 that keeps domain and event
state across requests.

## Integration

| | Details |
| --- | --- |
| API | Mailgun v3 |
| Auth | Synthetic bearer token. Mailgun's live API uses HTTP Basic. |
| Hosts | `api.mailgun.net` |
| Direct URL | Yes |
| Transparent proxy | Yes |

### Start it with a direct URL

Use `fab run` without `--proxy`. The command below downloads Fabricate's
example manifest directly, so you do not need to clone this repository.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-mailgun.yaml | \
  fab run /dev/stdin -- \
    sh -c 'curl -sS -H "Authorization: Bearer $FAB_MAILGUN_TOKEN" "$FAB_MAILGUN_URL/v4/domains"'
```

The service is named `mailgun` in the example manifest, so the variables are
`FAB_MAILGUN_URL` and `FAB_MAILGUN_TOKEN`.

### Start it through the proxy

Use this when your app uses the normal Mailgun URLs. This one-paste check
calls Mailgun's production hostname; the proxy supplies the local token.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-mailgun.yaml | \
  fab run /dev/stdin --proxy -- \
    curl -sS https://api.mailgun.net/v4/domains
```

Fabricate handles `api.mailgun.net` locally. Other hosts are forwarded unchanged.
