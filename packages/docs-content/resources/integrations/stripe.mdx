Fabricate ships a Stripe v1 resource with a strict local API and a
synthetic bearer token. It covers customer list, get, and create in the included
Acme Stripe environment.

## Scenarios

| Scenario | What it gives you |
| --- | --- |
| `stripe.minimal.v1` | Empty Stripe state for a clean test. |
| `stripe.acme-customers.v1` | Northwind, Contoso, and Helix Bio billing customers. |

## Integration options

| Option | Supported | Use it when |
| --- | --- | --- |
| Direct base URL | Yes | Your client can use a local URL or root URL. |
| Transparent proxy | Yes | Your client must keep Stripe’s normal hostnames. |

### Start it with a direct URL

Use `fab run` without `--proxy`. The command below downloads Fabricate's
example manifest directly, so you do not need to clone this repository.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-stripe.yaml | \
  fab run --environment /dev/stdin -- \
    sh -c 'curl -sS -H "Authorization: Bearer $FAB_STRIPE_TOKEN" "$FAB_STRIPE_URL/v1/customers"'
```

The service is named `stripe` in the example manifest, so the variables are
`FAB_STRIPE_URL` and `FAB_STRIPE_TOKEN`.

### Start it through the proxy

Use this when your app uses the normal Stripe URLs. This one-paste check
calls Stripe's production hostname; the proxy supplies the local token.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-stripe.yaml | \
  fab run --environment /dev/stdin --proxy -- \
    curl -sS https://api.stripe.com/v1/customers
```

Fabricate handles `api.stripe.com` locally. Other hosts are forwarded unchanged.
