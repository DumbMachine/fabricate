Employees, departments, time off types, and time off requests. Local BambooHR
v1 for the Acme company subdomain that keeps people and time off across
requests.

## Integration

| | Details |
| --- | --- |
| API | BambooHR v1 |
| Auth | Synthetic bearer token. BambooHR production uses HTTP Basic (API key as the username). |
| Hosts | `acme.bamboohr.com` |
| Direct URL | Yes |
| Transparent proxy | Yes |

BambooHR authenticates with HTTP Basic: the API key is the username and the
password can be any string. Fabricate accepts `Authorization: Bearer` instead.
The proxy overwrites `Authorization` on `acme.bamboohr.com` with the
environment's ephemeral bearer token, so existing clients keep working without
a Basic header.

The employee `status` field is only `Active` or `Inactive`. Jordan Hale's
Onboarding value is `employmentStatus`, with `hireDate` `2026-09-08` and
`status` `Inactive`.

### Start it with a direct URL

Use `fab run` without `--proxy`. The command below downloads Fabricate's
example manifest directly, so you do not need to clone this repository.
Fabricate injects a URL and a short-lived token for the service name in that
manifest.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-bamboohr.yaml | \
  fab run /dev/stdin -- \
    sh -c 'curl -sS -H "Authorization: Bearer $FAB_BAMBOOHR_TOKEN" \
      "$FAB_BAMBOOHR_URL/api/v1/employees?fields=workEmail,departmentName,employmentStatus,hireDate"'
```

The service is named `bamboohr` in the example manifest, so the variables are
`FAB_BAMBOOHR_URL` and `FAB_BAMBOOHR_TOKEN`.

### Start it through the proxy

Use this when your app uses the normal BambooHR company URL and follows
standard proxy and CA environment variables. This one-paste check calls
Acme's production hostname; replace the final `curl` with your app. Omit
`$FAB_BAMBOOHR_TOKEN` here: the proxy replaces `Authorization` on routed hosts
with the environment's ephemeral token.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-bamboohr.yaml | \
  fab run /dev/stdin --proxy -- \
    curl -sS "https://acme.bamboohr.com/api/v1/employees?fields=workEmail,departmentName,employmentStatus,hireDate"
```

Fabricate handles `acme.bamboohr.com` locally. Other hosts are forwarded
unchanged; set `proxy.unknown_hosts: reject` for an isolated, fail-closed
conformance test.

The proxy will not help an application that pins certificates or ignores proxy
settings. In that case, use the direct URL.
