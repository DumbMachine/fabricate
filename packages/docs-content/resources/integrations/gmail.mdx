Messages, threads, labels, profile, and send. Local Gmail v1 that keeps
mailbox state across requests.

## Integration

| | Details |
| --- | --- |
| API | Gmail v1 |
| Auth | Synthetic bearer token. The proxy also refreshes Google OAuth. |
| Hosts | `gmail.googleapis.com`, Gmail paths on `www.googleapis.com` |
| Direct URL | Yes |
| Transparent proxy | Yes |

### Start it with a direct URL

Use `fab run` without `--proxy`. The command below downloads Fabricate's
example manifest directly, so you do not need to clone this repository.
Fabricate injects a URL and a short-lived token for the service name in that
manifest.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-gmail.yaml | \
  fab run --environment /dev/stdin -- \
    sh -c 'curl -sS -H "Authorization: Bearer $FAB_SUPPORT_MAIL_TOKEN" \
      "$FAB_SUPPORT_MAIL_URL/gmail/v1/users/me/messages"'
```

The service is named `support-mail` in the example manifest, so the variables
are `FAB_SUPPORT_MAIL_URL` and `FAB_SUPPORT_MAIL_TOKEN`. If you name the
service `gmail`, they become `FAB_GMAIL_URL` and `FAB_GMAIL_TOKEN`.

### Start it through the proxy

Use this when your app uses the normal Gmail/Google URLs and follows standard
proxy and CA environment variables. This one-paste check calls Gmail's normal
production hostname; replace the final `sh -c ...` command with your app.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-gmail.yaml | \
  fab run --environment /dev/stdin --proxy -- \
    sh -c 'curl -sS -H "Authorization: Bearer $FAB_SUPPORT_MAIL_TOKEN" \
      "https://gmail.googleapis.com/gmail/v1/users/me/messages"'
```

Fabricate handles `gmail.googleapis.com` and the Gmail path on
`www.googleapis.com` locally, including the token-refresh route. Other hosts
are forwarded unchanged; set `proxy.unknown_hosts: reject` for an isolated,
fail-closed conformance test.

The proxy will not help an application that pins certificates or ignores proxy
settings. In that case, use the direct URL.
