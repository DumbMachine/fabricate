### Start it with a direct URL

Use `fab run` without `--proxy`. The command below downloads Fabricate's
example manifest directly, so you do not need to clone this repository.
Fabricate injects a URL and a short-lived token for the service name in that
manifest.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-gainsight.yaml | \
  fab run /dev/stdin -- \
    sh -c "curl -sS -H \"Authorization: Bearer \$FAB_GAINSIGHT_TOKEN\" -H \"Content-Type: application/json\" -X POST \"\$FAB_GAINSIGHT_URL/v1/data/objects/query/Company\" -d '{\"select\":[\"Name\",\"Gsid\",\"Health__gc\",\"Status\"],\"limit\":100,\"offset\":0}'"
```

The service is named `gainsight` in the example manifest, so the variables are
`FAB_GAINSIGHT_URL` and `FAB_GAINSIGHT_TOKEN`.

The response is the Acme customer list. `requestId` is generated for that call and is not stored in the scenario. The value below shows the shape only:

```json
{
  "data": [
    {
      "Gsid": "company-contoso",
      "Health__gc": "Red",
      "Name": "Contoso",
      "Status": "Active"
    },
    {
      "Gsid": "company-fernworks",
      "Health__gc": "Green",
      "Name": "Fernworks",
      "Status": "Active"
    },
    {
      "Gsid": "company-northwind",
      "Health__gc": "Red",
      "Name": "Northwind Traders",
      "Status": "Active"
    },
    {
      "Gsid": "company-tinyshop",

  "errorCode": null,

  "result": true
}
```

### Start it through the proxy

Use this when your app uses the normal Gainsight URLs and follows standard
proxy and CA environment variables. This one-paste check calls the Acme
Gainsight hostname; replace the final `curl` with your app. Omit
`$FAB_GAINSIGHT_TOKEN` here: the proxy replaces `Authorization` on routed
hosts with the environment's ephemeral token.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-gainsight.yaml | \
  fab run /dev/stdin --proxy -- \
    curl -sS -H 'Content-Type: application/json' \
      -d '{"select":["Name","Gsid","Health__gc","Status"],"limit":100,"offset":0}' \
      -X POST https://acme.gainsightcloud.com/v1/data/objects/query/Company
```

Fabricate handles `acme.gainsightcloud.com` locally. Other hosts are forwarded
unchanged; set `proxy.unknown_hosts: reject` for an isolated, fail-closed
conformance test.

The proxy will not help an application that pins certificates or ignores proxy
settings. In that case, use the direct URL.
