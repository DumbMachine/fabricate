Accounts, users, envelopes, recipients, and documents. Local DocuSign
eSignature REST API v2.1 that keeps envelope state across requests.

## Integration

| | Details |
| --- | --- |
| API | DocuSign eSignature REST API v2.1 |
| Auth | Synthetic bearer token |
| Hosts | `demo.docusign.net` |
| Direct URL | Yes |
| Transparent proxy | Yes |

### Start it with a direct URL

Use `fab run` without `--proxy`. The command below downloads Fabricate's
example manifest directly, so you do not need to clone this repository.
Fabricate injects a URL and a short-lived token for the service name in that
manifest.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-docusign.yaml | \
  fab run /dev/stdin -- \
    sh -c 'curl -sS -H "Authorization: Bearer $FAB_DOCUSIGN_TOKEN" \
      "$FAB_DOCUSIGN_URL/restapi/v2.1/accounts/acct-acme/envelopes"'
```

The service is named `docusign` in the example manifest, so the variables are
`FAB_DOCUSIGN_URL` and `FAB_DOCUSIGN_TOKEN`.

### Start it through the proxy

Use this when your app uses the normal DocuSign URLs and follows standard proxy
and CA environment variables. This one-paste check calls DocuSign's demo
hostname; replace the final `curl` with your app. Omit `$FAB_DOCUSIGN_TOKEN`
here: the proxy replaces `Authorization` on routed hosts with the
environment's ephemeral token.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-docusign.yaml | \
  fab run /dev/stdin --proxy -- \
    curl -sS https://demo.docusign.net/restapi/v2.1/accounts/acct-acme/envelopes
```

Fabricate handles `/restapi/` on `demo.docusign.net` locally. Other hosts are
forwarded unchanged; set `proxy.unknown_hosts: reject` for an isolated,
fail-closed conformance test.

The proxy will not help an application that pins certificates or ignores proxy
settings. In that case, use the direct URL.
