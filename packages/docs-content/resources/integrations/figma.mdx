Files, comments, webhooks, and teams. Local Figma v1 that keeps file and
webhook state across requests.

## Integration

| | Details |
| --- | --- |
| API | Figma v1 |
| Auth | Synthetic bearer token |
| Hosts | `api.figma.com` |
| Direct URL | Yes |
| Transparent proxy | Yes |

### Start it with a direct URL

Use `fab run` without `--proxy`. The command below downloads Fabricate's
example manifest directly, so you do not need to clone this repository.
Fabricate injects a URL and a short-lived token for the service name in that
manifest.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-figma.yaml | \
  fab run /dev/stdin -- \
    sh -c 'curl -sS -H "Authorization: Bearer $FAB_FIGMA_TOKEN" \
      "$FAB_FIGMA_URL/v2/teams/team_acme/webhooks"'
```

The service is named `figma` in the example manifest, so the variables are
`FAB_FIGMA_URL` and `FAB_FIGMA_TOKEN`.

The response is the Acme webhook list:

### Start it through the proxy

Use this when your app uses the normal Figma URLs. This one-paste check
calls Figma's production hostname. Omit `$FAB_FIGMA_TOKEN`; the proxy replaces `Authorization` on that host with the environment's ephemeral token.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-figma.yaml | \
  fab run /dev/stdin --proxy -- \
    curl -sS https://api.figma.com/v2/teams/team_acme/webhooks
```

Fabricate handles `api.figma.com` locally. Other hosts are forwarded unchanged.
