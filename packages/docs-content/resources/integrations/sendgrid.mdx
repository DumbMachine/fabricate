Mail send and batches. Local SendGrid v3 that keeps batch state across
requests.

## Integration

| | Details |
| --- | --- |
| API | SendGrid v3 |
| Auth | Synthetic bearer token |
| Hosts | `api.sendgrid.com` |
| Direct URL | Yes |
| Transparent proxy | Yes |

### Start it with a direct URL

Use `fab run` without `--proxy`. The command below downloads Fabricate's
example manifest directly, so you do not need to clone this repository.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-sendgrid.yaml | \
  fab run /dev/stdin -- \
    sh -c 'curl -sS -H "Authorization: Bearer $FAB_SENDGRID_TOKEN" -X POST "$FAB_SENDGRID_URL/v3/mail/batch"'
```

The service is named `sendgrid` in the example manifest, so the variables are
`FAB_SENDGRID_URL` and `FAB_SENDGRID_TOKEN`.

### Start it through the proxy

Use this when your app uses the normal SendGrid URLs. This one-paste check
calls SendGrid's production hostname. Omit `$FAB_SENDGRID_TOKEN`; the proxy replaces `Authorization` on that host with the environment's ephemeral token.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-sendgrid.yaml | \
  fab run /dev/stdin --proxy -- \
    curl -sS -X POST https://api.sendgrid.com/v3/mail/batch
```

Fabricate handles `api.sendgrid.com` locally. Other hosts are forwarded unchanged.
