Shop, products, variants, customers, orders, fulfillments, and refunds. Local
Shopify Admin REST 2024-10 that keeps shop state across requests.

## Integration

| | Details |
| --- | --- |
| API | Shopify Admin REST 2024-10 |
| Auth | Bearer token or `X-Shopify-Access-Token` |
| Hosts | `acme-goods.myshopify.com`, `northwind-market.myshopify.com`, `tinyshop.myshopify.com`, `fernworks-studio.myshopify.com` |
| Direct URL | Yes |
| Transparent proxy | Yes |

### Start it with a direct URL

Use `fab run` without `--proxy`. The command below downloads Fabricate's
example manifest directly, so you do not need to clone this repository.
Fabricate injects a URL and a short-lived token for the service name in that
manifest.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-shopify.yaml | \
  fab run /dev/stdin -- \
    sh -c 'curl -sS -H "Authorization: Bearer $FAB_SHOPIFY_TOKEN" \
      "$FAB_SHOPIFY_URL/admin/api/2024-10/orders/10482.json"'
```

The service is named `shopify` in the example manifest, so the variables are
`FAB_SHOPIFY_URL` and `FAB_SHOPIFY_TOKEN`. A direct request can send that
token as `Authorization: Bearer` or as `X-Shopify-Access-Token`. When the
`Host` header is not one of the shop domains above, the server uses the
scenario's current shop, Acme Goods.

### Start it through the proxy

Use this when your app uses the normal Shopify shop URL and follows standard
proxy and CA environment variables. This one-paste check calls Acme Goods'
production hostname; replace the final `curl` with your app. Omit
`$FAB_SHOPIFY_TOKEN` here: the proxy replaces `Authorization` on routed hosts
with the environment's ephemeral token.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-shopify.yaml | \
  fab run /dev/stdin --proxy -- \
    curl -sS https://acme-goods.myshopify.com/admin/api/2024-10/orders/10482.json
```

Fabricate handles the four shop hosts locally. Other hosts are forwarded
unchanged; set `proxy.unknown_hosts: reject` for an isolated, fail-closed
conformance test.

The proxy will not help an application that pins certificates or ignores proxy
settings. In that case, use the direct URL.
