Fabricate ships an Attio v2 resource with a strict local API and a
synthetic bearer token. It covers people, companies, and deals in the included Acme Attio
environment.

## Scenarios

| Scenario | What it gives you |
| --- | --- |
| `attio.minimal.v1` | Empty Attio state for a clean test. |
| `attio.acme-workspace.v1` | Dana at Northwind, INV-4812, Contoso SSO, and Fernworks. |

## Integration options

| Option | Supported | Use it when |
| --- | --- | --- |
| Direct base URL | Yes | Your client can use a local URL or root URL. |
| Transparent proxy | Yes | Your client must keep Attio’s normal hostnames. |

### Start it with a direct URL

Use `fab run` without `--proxy`. The command below downloads Fabricate's
example manifest directly, so you do not need to clone this repository.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-attio.yaml | \
  fab run --environment /dev/stdin -- \
    sh -c 'curl -sS -H "Authorization: Bearer $FAB_ATTIO_TOKEN" "$FAB_ATTIO_URL/v2/objects"'
```

The service is named `attio` in the example manifest, so the variables are
`FAB_ATTIO_URL` and `FAB_ATTIO_TOKEN`.

### Start it through the proxy

Use this when your app uses the normal Attio URLs. This one-paste check
calls Attio's production hostname; the proxy supplies the local token.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-attio.yaml | \
  fab run --environment /dev/stdin --proxy -- \
    curl -sS -H 'Content-Type: application/json' -d '{}' https://api.attio.com/v2/objects/people/records/query
```

Fabricate handles `api.attio.com` locally. Other hosts are forwarded unchanged.
