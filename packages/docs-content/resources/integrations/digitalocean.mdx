Fabricate ships a DigitalOcean v1 resource with a local API driven by the official DigitalOcean OpenAPI document and a synthetic bearer token. Every operation in that document is implemented. The included Acme DigitalOcean environment seeds a SaaS-sized droplet/volume catalog plus the shared Acme investigation needles. Gmail, Asana, and HubSpot run in the same environment so agents can join those facts across products.

## Scenarios

| Scenario | What it gives you |
| --- | --- |
| `digitalocean.minimal.v1` | Empty DigitalOcean state for a clean test. |
| `digitalocean.acme-droplets.v1` | Acme compute estate: droplets, volumes, SSH keys, and domains. Needles: `acme-web` checkout reliability, Contoso SSO API, INV-4812 billing, fernworks analytics, Adatum DNS, LakeTech hooks. |

## Integration options

| Option | Supported | Use it when |
| --- | --- | --- |
| Direct base URL | Yes | Your client can use a local URL or root URL. |
| Transparent proxy | Yes | Your client must keep DigitalOcean’s normal hostnames. |

### Start it with a direct URL

Use `fab run` without `--proxy`. The command below downloads Fabricate's
example manifest directly, so you do not need to clone this repository.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-digitalocean.yaml | \
  fab run --environment /dev/stdin -- \
    sh -c 'curl -sS -H "Authorization: Bearer $FAB_DIGITALOCEAN_TOKEN" "$FAB_DIGITALOCEAN_URL/v2/droplets"'
```

The service is named `digitalocean` in the example manifest, so the variables are
`FAB_DIGITALOCEAN_URL` and `FAB_DIGITALOCEAN_TOKEN`.

### Start it through the proxy

Use this when your app uses the normal DigitalOcean URLs. This one-paste check
calls DigitalOcean's production hostname; the proxy supplies the local token.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-digitalocean.yaml | \
  fab run --environment /dev/stdin --proxy -- \
    curl -sS https://api.digitalocean.com/v2/droplets
```

Fabricate handles `api.digitalocean.com` locally. Other hosts are forwarded unchanged.
