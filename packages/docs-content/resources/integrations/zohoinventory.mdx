Organizations, warehouses, items, sales orders, and purchase orders. Local
Zoho Inventory API v1 that keeps stock and purchase-order approval across
requests.

## Integration

| | Details |
| --- | --- |
| API | Zoho Inventory API v1 |
| Auth | Synthetic bearer token. Zoho Inventory live API uses `Authorization: Zoho-oauthtoken`. |
| Hosts | `www.zohoapis.com` |
| Direct URL | Yes |
| Transparent proxy | Yes |

### Start it with a direct URL

Use `fab run` without `--proxy`. The command below downloads Fabricate's
example manifest directly, so you do not need to clone this repository.
Fabricate injects a URL and a short-lived token for the service name in that
manifest.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-zohoinventory.yaml | \
  fab run /dev/stdin -- \
    sh -c 'curl -sS -H "Authorization: Bearer $FAB_ZOHOINVENTORY_TOKEN" \
      "$FAB_ZOHOINVENTORY_URL/inventory/v1/items?organization_id=org-acme"'
```

The service is named `zohoinventory` in the example manifest, so the variables
are `FAB_ZOHOINVENTORY_URL` and `FAB_ZOHOINVENTORY_TOKEN`. Every Inventory call
except the organization list and get takes `organization_id=org-acme`.

### Start it through the proxy

Use this when your app uses the normal Zoho Inventory URLs and follows standard
proxy and CA environment variables. This one-paste check calls Zoho's normal
production hostname; replace the final `curl` with your app. Omit
`$FAB_ZOHOINVENTORY_TOKEN` here: the proxy replaces `Authorization` on routed
hosts with the environment's ephemeral token.

```bash
curl -fsSL https://raw.githubusercontent.com/DumbMachine/fabricate/main/environments/acme-zohoinventory.yaml | \
  fab run /dev/stdin --proxy -- \
    curl -sS "https://www.zohoapis.com/inventory/v1/items?organization_id=org-acme"
```

Fabricate handles `www.zohoapis.com` paths under `/inventory/` locally. Paths
outside that prefix, including Zoho Books under `/books/`, are not this
resource. Other hosts are forwarded unchanged; set `proxy.unknown_hosts: reject`
for an isolated, fail-closed conformance test.

The proxy will not help an application that pins certificates or ignores proxy
settings. In that case, use the direct URL.
